> BREVETTO CONCESSO · US10346463B2

Selezione di risultati locali tramite query visiva e localizzazione

Titolo originale: Hybrid use of location sensor data and visual query to return local listings for visual query

Il brevetto descrive un sistema che riceve una query visiva (un'immagine) e informazioni sulla posizione del dispositivo client, confronta l'immagine con un corpus di immagini street view per ottenere una posizione più accurata (enhanced location), e utilizza questa posizione raffinata per restituire risultati di ricerca locale (local listings) filtrati e ordinati in base a vicinanza e prominenza.

> COSA RIVENDICA

La rivendicazione indipendente 1 protegge un metodo che riceve una image query da un client system e identifica la posizione del client. Il sistema determina un accuracy value che specifica quanto la posizione identificata corrisponda alla posizione reale del client. Identifica una pluralità di search results basati sull'image query e sulla posizione, ciascuno con un prominence value (importanza relativa del risultato) e un closeness metric (quanto la location dell'entità è vicina alla posizione del client). Se l'accuracy value soddisfa una threshold, il sistema applica un first weighting factor al closeness metric e un second weighting factor al prominence value, dando più peso alla vicinanza che alla prominenza. Seleziona uno o più risultati basandosi sui valori pesati e li invia al client.

La rivendicazione 2 aggiunge che se l'accuracy value non soddisfa la threshold, il sistema regola i weighting factors in modo che il closeness metric riceva meno peso del prominence value nella selezione dei risultati. La rivendicazione 3 specifica che l'identificazione dei search results include l'identificazione di un positional accuracy value per la location di ciascuna entità referenziata. La rivendicazione 4 aggiunge che la selezione include l'identificazione di un closeness metric e la selezione di risultati che soddisfano sia un closeness threshold che un accuracy threshold. La rivendicazione 5 contempla l'inclusione di risultati con positional accuracy insufficiente se si trovano entro una threshold distance da un'entità con buona accuracy e closeness. La rivendicazione 6 descrive come identificare la location del client: ottenendo location information dal client (first location), confrontando l'immagine con immagini di entità in un predefined range della first location, determinando una enhanced location usando image location information dell'entità riconosciuta, e designando questa enhanced location come location del client.

> LETTURA SEO (INTERPRETAZIONE)

La descrizione contempla un sistema in cui un visual query server system (blocco 106) riceve sia un'immagine che location information dal client (operazioni 202, 1602). Il sistema invia la visual query e la location information a un visual query search system (operazione 1610), specificamente a un location-augmented search system (112-F, figura 23) che esegue un match search su un corpus di street view images (database 2322) entro un range specificato dalla location information del client. Se trova un match, il sistema restituisce enhanced location information con maggiore accuracy della location information originale (operazione 1614, blocco 1616). Tipicamente l'enhanced location identifica la posizione entro 10-15 piedi dalla posizione reale (descrizione a 1614). La descrizione contempla anche l'inclusione di pose information (direzione in cui guarda l'utente) nell'enhanced location (blocco 1618).

Il sistema invia poi una search query a un location-based search system (112-G, figura 24, operazione 1620) che include l'enhanced location information. Questo sistema utilizza un location database (2422) contenente records (2406) con location information (2310), accuracy of location (2432), postal address (2434), prominence value (2436) e associated information (2308). La descrizione contempla diversi metodi di selezione dei risultati. Il metodo del frustum (figura 17) costruisce un viewing frustum basato sulla posizione del client e sul pose, con lunghezza variabile in funzione dell'accuracy: short range (meno di 100 yards) per alta accuracy, large range (più di short range, meno di 500 yards) per bassa accuracy (blocchi 1702-1706). I risultati fuori dal frustum vengono esclusi (blocco 1712).

Il metodo prominence/location (figura 18) identifica un accuracy value per l'enhanced location e un prominence value per ciascun risultato (blocchi 1802, 1804). Quando l'enhanced location ha accuracy sopra una threshold, il sistema favorisce risultati vicini usando un primo set di weighting factors che privilegia closeness (esempio: 0.8 per closeness, 0.2 per prominence, blocco 1812). Quando l'accuracy è sotto threshold, usa un secondo set che privilegia prominence (esempio: 0.2 per closeness, 0.8 per prominence, blocco 1814). Questo potrebbe significare che per query con posizione incerta Google potrebbe privilegiare entità famose o ben recensite rispetto a quelle semplicemente più vicine alla posizione stimata. Per query con posizione precisa, la prossimità geografica potrebbe contare più della notorietà dell'entità.

> COSA NON DIMOSTRA

  • Il brevetto non dimostra che questo sistema sia attivo in Google Lens, Google Maps o altri prodotti Google. La data di priorità (2009) precede l'era delle ricerche visive moderne e potrebbe descrivere tecnologie superate.
  • Il brevetto riguarda specificamente visual queries abbinate a location information per restituire local listings. Non si applica alla ricerca web testuale tradizionale né alla SEO di contenuti non locali.
  • La descrizione non specifica come vengano calcolati i prominence values delle entità locali né quali fattori (recensioni, traffico, link, menzioni) contribuiscano a questo valore.
  • Il brevetto è parte di una famiglia con continuation (US9852156B2), quindi non rappresenta una protezione indipendente ma un'estensione di rivendicazioni precedenti.

> COSA FARE COMUNQUE

  1. Per attività locali, mantenere informazioni di location accurate e coerenti su tutte le piattaforme (Google Business Profile, mappe, directory) rimane fondamentale indipendentemente da questo brevetto, poiché l'accuracy della posizione influenza la visibilità.
  2. Costruire prominence attraverso recensioni verificate, engagement degli utenti e presenza consolidata nel tempo ha valore per la visibilità locale, indipendentemente dai meccanismi specifici di ranking.
  3. Per business locali, assicurarsi che le informazioni di indirizzo, punto di ingresso e orientamento dell'edificio siano corrette nei database geografici aiuta l'associazione corretta tra posizione fisica e entità digitale.
  4. Considerare che le ricerche locali da dispositivi mobili potrebbero comportarsi diversamente in base all'accuratezza del segnale GPS: in aree urbane dense o indoor l'accuratezza può degradare significativamente.
