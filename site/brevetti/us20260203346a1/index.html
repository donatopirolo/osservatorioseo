> DOMANDA DI BREVETTO · US20260203346A1

Generazione di risposte a ricerche visive basate su intent

Titolo originale: Intent Determination-Based Visual Search Response Generation

Il brevetto descrive un sistema per ricerca visiva che determina l'intent di una query basata su immagini (anche senza testo), seleziona un prompt specifico da una libreria in base all'intent rilevato, recupera risultati di ricerca visiva e genera una risposta con un modello generativo condizionato dal prompt scelto. L'obiettivo è fornire risposte formattate diversamente a seconda dell'intento (es. risoluzione compiti, identificazione oggetti, contesto di una scena).

> COSA RIVENDICA

La rivendicazione 1 protegge un sistema che ottiene una query immagine raffigurante più feature, la elabora con un modello addestrato per determinare un intent di ricerca predetto dell'utente, determina un prompt particolare associato a quell'intent da una libreria di prompt, identifica una pluralità di content item tramite visual match, e processa il prompt e almeno un sottoinsieme dei content item con un modello linguistico generativo per generare una risposta il cui formato è basato sull'intent e i cui dettagli derivano dai content item.

La rivendicazione 2 specifica che il prompt può essere selezionato generando un intent embedding e cercando nella libreria. La rivendicazione 3 indica che i diversi prompt sono associati a diversi tipi di search intent. La rivendicazione 4 elenca tipi di intent specifici: homework solver, context search, identification search, detailed breakdown search. La rivendicazione 5 precisa che la query può essere unimodale. La rivendicazione 6 descrive il prompt come una richiesta di formato e stile particolari per la risposta. La rivendicazione 7 contempla che il prompt possa essere un soft prompt (set di pesi pre-tuned per un task specifico). Le rivendicazioni 8-10 descrivono l'acquisizione dell'immagine tramite viewfinder di un'app di ricerca e la visualizzazione della risposta con i risultati e parte del viewfinder.

La rivendicazione 11 (metodo indipendente) protegge l'elaborazione della query con un modello di object recognition per generare label, poi con un semantic understanding model per generare output semantico (relazioni tra oggetti), determinazione di content item via search engine, e generazione della risposta processando label, output semantico e content item con il modello generativo. La rivendicazione 12 specifica che l'output semantico può includere classificazione dell'immagine e identificazione di oggetti di interesse. La rivendicazione 13 contempla il caso di frame di film/show con risposta strutturata in sezioni. La rivendicazione 14 indica che l'output semantico può includere un intent determination. La rivendicazione 15 descrive un generative orchestrator model che coordina i modelli di recognition e semantic understanding. La rivendicazione 16 dettaglia la selezione di un sottoinsieme di label associate all'intent e di un prompt per generare la risposta.

La rivendicazione 17 (media non transitori) copre l'ottenimento della query via viewfinder, determinazione dell'intent (basata su oggetti e classificazione immagine), selezione del prompt, ricerca di content item, generazione della risposta e visualizzazione con i risultati. La rivendicazione 18 specifica l'homework solver intent (problemi non risolti nella regione focale). La rivendicazione 19 descrive l'identification intent (feature set nella regione focale). La rivendicazione 20 indica che l'identification intent può essere determinato anche in base a contesto utente (location, search/browsing history, preferenze, occupazione).

> LETTURA SEO (INTERPRETAZIONE)

La descrizione contempla diversi segnali e meccanismi. Il sistema può utilizzare un machine-learned model addestrato a processare immagini e determinare query intent (blocco 104, 204, rivendicazione 1). La descrizione menziona tipi di intent specifici: homework solver search intent, context search intent, identification search intent, detailed breakdown search intent (rivendicazione 4, FIG. 6 con classificazioni 602-608). Per il homework intent, la descrizione contempla il riconoscimento di problemi non risolti in una focal region (rivendicazione 18). Per l'identification intent, si considerano feature set nella focal region e contesto utente come location, search history, browsing history, preferenze, occupazione (rivendicazioni 19-20).

La descrizione contempla una prompt library con diversi prompt associati a diversi search intent types (rivendicazione 3). Il prompt può essere selezionato generando un intent embedding e cercando nella libreria (rivendicazione 2). I prompt possono essere soft prompt, cioè set di pesi pre-tuned per task specifici (rivendicazione 7). La descrizione menziona object recognition model e semantic understanding model che possono essere coordinati da un generative orchestrator model (rivendicazione 15). L'output semantico può includere image classification, identificazione di oggetti di interesse, relazioni tra oggetti (rivendicazioni 11-12). Per frame di film/show, la risposta potrebbe includere sezioni con dettagli di contesto diversi (rivendicazione 13, FIG. 5A con esempio 508).

I content item sono determinati tramite visual match (rivendicazione 1), che la descrizione associa a embedding-based search, feature matching, label-based search. La risposta generata include un formato basato sull'intent e dettagli dai content item (rivendicazione 1). Gli esempi nelle figure (FIG. 4-5B, 10, 14-15) mostrano interfacce con risposte strutturate diversamente: identificazione con dettagli (FIG. 4), contesto di scena cinematografica con sezioni (FIG. 5A), identificazione e contesto DIY (FIG. 5B).

Per la SEO, questo potrebbe significare che Google potrebbe differenziare le risposte generate in base all'intent rilevato da un'immagine. Un sito che fornisce contenuti strutturati per diversi intent (tutorial passo-passo per problemi, schede informative per identificazione, contesto dettagliato per media) potrebbe essere favorito come fonte per le risposte generate. La presenza di visual match (immagini simili indicizzate) resterebbe un segnale di partenza per il retrieval. Il contesto utente (cronologia, preferenze) potrebbe influenzare la classificazione dell'intent, suggerendo una certa personalizzazione. Tuttavia, la descrizione non afferma che questo sistema sia in produzione in Google Search: contempla applicazioni in search application, viewfinder interface, ma anche scenari generici di visual query response.

> COSA NON DIMOSTRA

  • Il brevetto è una domanda (A1), non ancora concessa, e non dimostra che Google applichi questo sistema in Search o in quale misura.
  • La descrizione contempla intent types e prompt selection, ma non specifica quali segnali di ranking dei content item siano utilizzati né come i contenuti vengano selezionati per inclusion nella risposta oltre ai visual match generici.
  • Il brevetto non dimostra che i soft prompt o la prompt library siano attualmente utilizzati, né fornisce dettagli su come i prompt siano costruiti o mantenuti.
  • L'ambito è la ricerca visiva unimodale in applicazioni di ricerca (incluso viewfinder), non necessariamente la ricerca web tradizionale; alcuni esempi (homework solver, frame identification) sono casi d'uso specifici che potrebbero non applicarsi a tutti i verticali SEO.

> COSA FARE COMUNQUE

  1. Fornire contenuti che rispondano a diversi intent di ricerca visiva (identificazione, contesto, how-to) in modo strutturato e dettagliato, anche se il brevetto non fosse applicato, migliora l'utilità per utenti che cercano informazioni su immagini.
  2. Includere immagini di qualità e descrittive nei contenuti facilita il visual matching e il retrieval da parte di motori di ricerca visiva, indipendentemente da questo brevetto.
  3. Strutturare i contenuti con sezioni chiare (es. panoramica, dettagli tecnici, istruzioni passo-passo) può aiutare modelli generativi a estrarre informazioni rilevanti, a prescindere dall'uso di prompt specifici.
  4. Considerare che le ricerche visive possono provenire da utenti con contesti diversi (principianti vs esperti, intenti diversi) e offrire contenuti adatti a più livelli di approfondimento resta una buona pratica editoriale.

> TERMINI CHIAVE

intent determination
Output di un modello che descrive l'intento di ricerca predetto dell'utente basato sull'immagine della query, utilizzato per selezionare il prompt e il formato della risposta.
prompt library
Raccolta di prompt (testuali o soft prompt) associati a diversi tipi di search intent, da cui il sistema seleziona il prompt particolare per condizionare il modello generativo.
soft prompt
Set di pesi machine-learned pre-tuned per un task specifico, utilizzato come input al modello generativo al posto di (o insieme a) prompt testuali, per condizionare la generazione.
visual match
Immagini o content item identificati come visivamente simili all'immagine della query, utilizzati come base per determinare i content item da cui estrarre dettagli per la risposta.
generative orchestrator model
Modello generativo che coordina e istruisce altri modelli (object recognition, semantic understanding) per processare la query immagine in modo orchestrato.
semantic understanding output
Output che descrive le relazioni tra oggetti nell'immagine, può includere classificazione dell'immagine, identificazione di oggetti di interesse e intent determination.
unimodal search query
Query composta da una sola modalità di input (solo immagine, senza testo), che pone sfide maggiori per determinare l'intent rispetto a query multimodali.
