> DOMANDA DI BREVETTO · US20260148736A1

Risposte multimodali con ragionamento multi-step per query complesse

Titolo originale: System For Generating Response To Multimodal Queries Using Multi-Step Reasoning

Il brevetto descrive un sistema che riceve query multimodali (testo e immagini), ne valuta la complessità e, se necessario, attiva un processo di ragionamento multi-step. Un sistema di orchestrazione genera un piano di azioni (analisi dell'immagine, estrazione di oggetti, generazione di sottoquery), esegue i passaggi, valuta se i dati raccolti sono sufficienti e, in caso contrario, ripete il ciclo. I dati intermedi vengono poi forniti a un modello generativo che produce una risposta in linguaggio naturale.

> COSA RIVENDICA

La rivendicazione indipendente 1 copre un metodo implementato da un sistema con uno o più processori per rispondere a una query multimodale con un modello linguistico di grandi dimensioni usando un processo di ragionamento multi-step. Il metodo prevede la ricezione di una query multimodale che include contenuto immagine. Il sistema determina che la query supera una soglia di complessità usando un modello di classificazione delle query. In risposta a questa determinazione, il sistema genera una pluralità di passaggi di elaborazione per rispondere alla query, dove i passaggi includono l'esecuzione di almeno una sottoquery basata sulla query multimodale. Il sistema esegue i passaggi per generare dati intermedi, genera un input basato sui dati intermedi, lo elabora con un modello di risposta per generare un output e trasmette l'output per la visualizzazione su un dispositivo utente.

Le rivendicazioni dipendenti aggiungono dettagli rilevanti. La rivendicazione 2 specifica che la query multimodale può includere contenuto testuale o vocale. La rivendicazione 3 indica che i passaggi possono essere rappresentati come una lista, e la 4 che ogni passaggio può essere rappresentato come un'istruzione computazionale. La rivendicazione 5 introduce un ciclo iterativo: prima di sintetizzare i dati intermedi, il sistema determina se sono sufficienti per rispondere alla query e, se non lo sono, un modello di orchestrazione genera passaggi aggiuntivi, li esegue per ottenere dati intermedi aggiornati e continua fino a quando i dati sono sufficienti. La rivendicazione 6 elenca i tipi di passaggi: riconoscimento di oggetti, recupero dati, esecuzione di sottoquery e sintesi dei dati. Le rivendicazioni 7-9 dettagliano questi passaggi: il riconoscimento di oggetti fornisce l'immagine a un modello addestrato che restituisce una lista di oggetti rilevati; l'esecuzione di sottoquery genera almeno una sottoquery basata sulla query originale e su almeno un oggetto rilevato, la fornisce a un sistema di ricerca e riceve risultati; la sintesi aggrega i risultati di ricerca in dati combinati e genera una sottoquery usando questi dati. La rivendicazione 10 spiega la classificazione della complessità: la query viene fornita al modello di classificazione che restituisce un punteggio di complessità, confrontato con la soglia. Le rivendicazioni 11-12 specificano che il modello di classificazione può essere un modello machine-learned addestrato per questo scopo o un large vision language model. La rivendicazione 13 indica che l'output può comprendere una risposta in linguaggio naturale. Le rivendicazioni 14-15 menzionano che l'input o l'output del modello possono includere dati di citazione. Le rivendicazioni 16-17 specificano che l'output può essere visualizzato in una pagina di risultati di ricerca, potenzialmente multimodali. Le rivendicazioni 18-20 coprono il sistema e i supporti non transitori che implementano lo stesso metodo.
