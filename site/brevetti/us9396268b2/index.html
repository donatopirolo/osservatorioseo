> BREVETTO CONCESSO · US9396268B2

Selezione e presentazione di answer box durante la digitazione

Titolo originale: Framework for selecting and presenting answer boxes relevant to user input as query suggestions

Il brevetto descrive un sistema per selezionare e presentare answer box mentre l'utente digita nella barra di ricerca, prima che invii la query. Il sistema identifica una dominant query dall'input parziale o analizza dati storici di presentazione degli answer box, quindi ottiene e mostra il contenuto dell'answer box più rilevante insieme ai suggerimenti di query.

> COSA RIVENDICA

La rivendicazione indipendente 1 copre un metodo implementato su computer che riceve input utente in un campo di ricerca e, mentre riceve l'input e prima che venga inviato come richiesta di ricerca, riceve da un sistema di presentazione un answer box associato a una specifica coppia input-answer box. Questa coppia viene selezionata da coppie candidate in base a un presentation value per ciascuna coppia. Le coppie candidate sono identificate da una pluralità di coppie input-answer box il cui text input corrisponde all'input utente. Il text input di ciascuna coppia è associato al rispettivo answer box se quell'answer box è stato presentato dal motore di ricerca in risposta a query che iniziano con un input corrispondente al text input. Il presentation value per ciascuna coppia è derivato dal numero di volte che l'answer box nella coppia è stato presentato dal motore in risposta a query che iniziano con l'input corrispondente al text input nella coppia. Il contenuto dell'answer box include un sommario di informazioni ritenute responsive a query che iniziano con input corrispondente al text input, ed è diverso dalla query e dai suggerimenti di query. L'answer box viene quindi presentato all'utente.

La rivendicazione 2 aggiunge che la coppia particolare può essere selezionata in base a un'indicazione che la coppia è stata utile agli utenti che hanno inviato query inizianti con input corrispondenti al text input nella coppia. La rivendicazione 3 contempla la ricezione di una pluralità di query suggestions per l'input utente, presentate insieme all'answer box. La rivendicazione 4 specifica che il presentation value può essere derivato dal numero di volte che l'answer box è stato presentato diviso per il numero totale di volte che query inizianti con input corrispondenti sono state ricevute dal motore. La rivendicazione 5 prevede una formula alternativa: il numero di presentazioni diviso per il numero totale di volte che uno o più utenti hanno inviato query per uno o più query suggestions per il text input nella coppia. Le rivendicazioni 6 e 7 specificano che gli utenti possono essere l'utente stesso o più utenti. Le rivendicazioni 8-21 sono formulate come sistema e computer storage media che implementano le stesse operazioni.

> LETTURA SEO (INTERPRETAZIONE)

La descrizione contempla diversi metodi per identificare quale answer box presentare durante la digitazione. Un approccio centrale è l'identificazione di una dominant query dall'input parziale. La descrizione contempla che la dominant query possa essere una completion dell'input, una modifica per correggere errori di ortografia, o una query correlata. La dominant query può essere selezionata da query suggestions in base a un popularity value, definito come il numero di volte che gli utenti inviano una query diviso per il totale delle query inviate per tutti i suggerimenti, o diviso per il totale delle query che iniziano con l'input. La descrizione contempla soglie di popolarità del 50%, 66% o 75% per selezionare la dominant query. La descrizione contempla anche l'uso di user search history per identificare query precedentemente inviate dall'utente che iniziano con text matching l'input, dove il text match può tollerare differenze in stop words, spelling, word order o sinonimi. La dominant query potrebbe essere selezionata se appare un numero di volte che soddisfa una soglia, ad esempio il 50% delle query inviate.

La descrizione contempla l'uso di user profile data per completare input incompleti, ad esempio aggiungendo la location dell'utente a query meteo che mancano di questa informazione. Contempla anche l'analisi del profilo per determinare categorie di answer box frequentemente richieste dall'utente, ad esempio presentando answer box finanziari se l'utente traccia frequentemente azioni. La descrizione contempla che il presentation value nei dati storici possa essere scalato, pesato per query che sono completions rispetto a query esatte, o pesato diversamente se l'answer box è stato presentato con risultati di ricerca rispetto a query suggestions. La descrizione contempla anche indicazioni di utilità degli answer box, come tempo di visualizzazione lungo, click su link nell'answer box, assenza di query refinement successive.

Per la SEO, questo brevetto potrebbe suggerire che Google valuti quali answer box presentare in base a pattern storici di presentazione e utilità percepita dagli utenti. Potrebbe significare che contenuti strutturati che alimentano answer box potrebbero essere mostrati anche per query parziali se storicamente quegli answer box sono stati presentati frequentemente per completions di quell'input. Tuttavia, il brevetto si concentra sulla selezione tra answer box già esistenti, non sulla selezione delle fonti per popolarli. La menzione di usefulness signals come click, tempo di visualizzazione e assenza di refinement potrebbe indicare che questi segnali influenzano quali answer box vengono privilegiati, ma il brevetto non afferma che questi segnali influenzino il ranking organico delle fonti.

> COSA NON DIMOSTRA

  • Il brevetto non dimostra che questo sistema sia attualmente in uso in Google Search, né che i segnali di utilità descritti influenzino il ranking organico dei siti che forniscono contenuti agli answer box.
  • Il brevetto si concentra sulla selezione di quale answer box presentare durante la digitazione, non su come vengono selezionate le fonti di contenuto per popolare gli answer box o su quali segnali determinano se un sito può diventare fonte di un answer box.
  • La descrizione contempla molte implementazioni alternative e segnali opzionali: non è possibile determinare quali siano effettivamente implementati senza informazioni esterne al brevetto.

> COSA FARE COMUNQUE

  1. Strutturare i contenuti in modo che rispondano direttamente a domande specifiche e complete, non solo a query parziali, aumenta la probabilità che possano alimentare answer box per query correlate.
  2. Monitorare per quali query il proprio sito appare in answer box e verificare se questi answer box vengono mostrati anche durante la digitazione di query parziali correlate.
  3. Considerare che gli utenti potrebbero non completare la digitazione se ricevono una risposta soddisfacente da un answer box durante la digitazione, riducendo potenzialmente il traffico da query complete.
  4. Ottimizzare per chiarezza e completezza delle risposte, dato che la descrizione contempla segnali di utilità come tempo di visualizzazione e assenza di query refinement.

> TERMINI CHIAVE

answer box
Presentazione formattata di contenuto rilevante per una query, organizzata secondo template specifici per categoria, che fornisce un sommario di informazioni responsive alla query
dominant query
Query che corrisponde all'input parziale dell'utente, può essere una completion, una modifica o una query correlata, identificata come la più probabile intenzione dell'utente
presentation value
Valore derivato dal numero di volte che un answer box è stato presentato in risposta a query che iniziano con un determinato input, usato per selezionare quale answer box mostrare
input-answer box pair
Associazione tra un text input e un answer box, creata quando quell'answer box è stato presentato in risposta a query che iniziano con input corrispondente al text input
popularity value
Misura derivata dal numero di volte che gli utenti inviano una query, tipicamente normalizzata sul totale delle query inviate per suggerimenti correlati o query che iniziano con lo stesso input
text matching
Corrispondenza tra testi che può essere identica o tollerare differenze in stop words, spelling, word order, sinonimi o combinazioni di queste eccezioni
