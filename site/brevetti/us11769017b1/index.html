> BREVETTO CONCESSO · US11769017B1

Sintesi generative per risultati di ricerca

Titolo originale: Generative summaries for search results

Il brevetto descrive un sistema per generare sintesi in linguaggio naturale in risposta a query utilizzando un large language model (LLM). Il sistema processa contenuti da documenti di risultati di ricerca selezionati (non solo la query) per generare la sintesi, con l'obiettivo di ridurre imprecisioni e rendere le sintesi più appropriate al contesto specifico della ricerca.

> COSA RIVENDICA

La rivendicazione indipendente 1 copre un metodo che riceve una query associata a un client device, genera output LLM processando input basato sulla query e/o contenuti da search result documents (SRD) responsivi alla query, genera una sintesi in linguaggio naturale (NL based summary) usando l'output LLM, e causa il rendering della sintesi insieme a link agli SRD. Il metodo include poi il monitoraggio di interazioni con gli SRD e, quando rileva un'interazione con un dato SRD, genera output LLM rivisto processando input rivisto che riflette l'occorrenza dell'interazione (mentre l'input originale non la rifletteva), genera una sintesi NL rivista usando l'output rivisto, e causa il rendering della sintesi rivista.

Le rivendicazioni dipendenti 2-3 specificano che l'interazione può includere la visualizzazione di almeno parte dell'SRD, opzionalmente per almeno una durata soglia. Le rivendicazioni 4-7 specificano diverse modalità di rendering della sintesi rivista: sostituendo la sintesi originale nell'interfaccia (rivendicazione 4), sostituendola dopo una durata iniziale di interazione (rivendicazione 5), in risposta a una nuova occorrenza della query (rivendicazione 6), o in risposta a una query aggiuntiva simile (rivendicazione 7). Le rivendicazioni 8-9 specificano modalità alternative per generare l'output rivisto: usando lo stesso LLM con un prompt rivisto che riflette familiarità con il contenuto dell'SRD (rivendicazione 8), o usando un LLM aggiuntivo fine-tuned su prompt che riflettono familiarità (rivendicazione 9). Le rivendicazioni 10-12 specificano che l'input può essere basato su contenuti da SRD responsivi alla query, selezionati tra SRD query-responsive e opzionalmente includendo SRD responsivi a related queries correlate.

La rivendicazione indipendente 13 copre un metodo alternativo che riceve una query, seleziona un set di SRD includendo SRD query-responsive, genera output LLM processando contenuti da ciascun SRD del set, genera una sintesi NL, genera una confidence measure per una porzione della sintesi, e causa il rendering della sintesi con una confidence annotation corrispondente alla confidence measure. Le rivendicazioni 14-17 specificano criteri di selezione degli SRD basati su query-dependent measures, query-independent measures, user-dependent measures (rivendicazione 15), e inclusione di SRD responsivi a related queries con correlazione che soddisfa una soglia (rivendicazioni 16-17). Le rivendicazioni 18-20 specificano il rendering di link selezionabili agli SRD, resi come parte della sintesi e corrispondenti a porzioni verificabili (rivendicazione 19-20). La rivendicazione 21 specifica che l'output LLM può essere generato senza processare la query stessa. La rivendicazione 22 specifica che la query può essere una implied query formulata e sottomessa automaticamente.

> LETTURA SEO (INTERPRETAZIONE)

La descrizione contempla numerosi dettagli operativi. Il blocco 254A (metodo 200) specifica che la selezione degli SRD può basarsi su query-dependent measures (positional ranking, selection rate per la query, locality measure basata su location della query e dell'SRD, language measure), query-independent measures (selection rate aggregata, trustworthiness measure, overall popularity, freshness measure che riflette recency di creazione o aggiornamento), e user-dependent measures (basate su attributi del profilo utente, query recenti, interazioni recenti non-query). Il blocco 256 contempla la selezione di related-query-responsive SRDs, dove la related query ha una correlazione con la query originale, con magnitude della correlazione basata su quantity di occorrenze delle due query emesse in temporal proximity da device o account corrispondenti. Il blocco 258 contempla la selezione di recent-query-responsive SRDs da query recenti dell'utente. Il blocco 259 contempla la selezione di implied-query-responsive SRDs da implied queries generate automaticamente da contesto e/o profile data.

Il blocco 260A1 contempla che il contenuto da un SRD può includere text content, image content (con recognized text, auto-generated caption, descriptor di oggetti rilevati), video content (con transcription dell'audio). Il blocco 260A1 contempla anche l'inclusione di source identifier unici per ciascun SRD nel contenuto processato dall'LLM, che potrebbero consentire all'output LLM di riflettere quali porzioni della sintesi sono supportate da quali SRD. Il blocco 262A contempla il rendering della sintesi con link agli SRD che verificano porzioni, con link resi come parte della sintesi (linkified portions) o come search results separati. Il blocco 262B contempla confidence annotations per porzioni o per l'intera sintesi. Il blocco 262C contempla la determinazione di quali SRD verificano porzioni comparando embeddings (content embedding della porzione vs document content embedding) e determinando distance measures, oppure usando source identifiers nell'output LLM.

Il metodo 400 (blocco 460A) contempla la generazione di sintesi riviste usando prompt rivisti che riflettono familiarità con contenuto già visto (es. "create a summary assuming the user already knows X"). Il metodo 600 (blocco 654A) contempla la determinazione di familiarità dell'utente con certi contenuti comparando profile data alla query e/o agli SRD. La descrizione contempla anche (paragrafo relativo a parallel LLMs) l'uso di multiple LLMs in parallelo per generare candidate summaries, selezionandone una basata su similarity ad altre candidate, presence/absence di certi termini, language model scores, o altre features.

Per la SEO, questi dettagli potrebbero suggerire che le sintesi generative potrebbero essere influenzate da: freshness e trustworthiness degli SRD selezionati, locality e language match con la query, selection rates degli SRD, user profile e query history, presenza di contenuti multimediali descrittivi (immagini con caption, video con transcript). La selezione di SRD da related queries e recent queries potrebbe favorire contenuti che appaiono in cluster tematici o in query sequences. La generazione di sintesi riviste in base a interazioni potrebbe premiare contenuti che l'utente effettivamente consulta. > TERMINI CHIAVE

LLM (Large Language Model)
Modello di linguaggio di grandi dimensioni (almeno centinaia di milioni di parametri, spesso miliardi) utilizzato per processare contenuti in linguaggio naturale e generare output generativo.
NL based summary
Sintesi in linguaggio naturale generata utilizzando l'output di un LLM, resa in risposta a una query.
search result document (SRD)
Documento di risultato di ricerca responsivo a una query, da cui vengono estratti contenuti da processare con l'LLM.
query-dependent measure
Misura dipendente dalla query specifica, come positional ranking, selection rate per quella query, locality measure, language measure.
query-independent measure
Misura indipendente dalla query, come selection rate aggregata, trustworthiness, overall popularity, freshness dell'SRD.
user-dependent measure
Misura dipendente dall'utente, basata su profilo utente, query recenti, interazioni recenti non-query.
related query
Query correlata alla query originale, determinata avere una correlazione (es. co-occorrenza in temporal proximity tra utenti).
implied query
Query generata e sottomessa automaticamente, indipendentemente da input utente esplicito, basata su contesto, profilo o altre informazioni.
