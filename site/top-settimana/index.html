Pre-addestramento su larga scala per le lingue indiane: 2.8 trilioni di token e una pipeline aperta per la generazione di dati

Hugging Face Blog · ★★★★☆ · 18 h fa // ID: 312B

NVIDIA e AI4Bharat hanno rilasciato Nemotron-pretraining-Indic-v1, un dataset di circa 2.8 trilioni di token per 22 lingue indiane.
