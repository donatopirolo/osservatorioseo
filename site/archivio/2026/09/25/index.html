Google annuncia il nuovo framework R4T-Diffusion per l'espansione delle query

Search Engine Journal · ★★★★☆ · 17 h fa // ID: 6F3A

Google ha introdotto R4T-Diffusion, un nuovo framework per l'espansione delle query che promette maggiore velocità, efficienza computazionale e qualità superiore. Questo sistema a tre stadi combina apprendimento per rinforzo, generazione di dati sintetici e una rete neurale generativa di dimensioni ridotte. L'obiettivo è produrre espansioni di query pertinenti e diversificate, evitando ridondanze. Il framework utilizza la distillazione di conoscenza per trasferire il comportamento di modelli più grandi a uno più piccolo, riducendo i costi computazionali e la latenza.
