Googlebot ora esegue un singolo passaggio di unescaping HTML per l'estrazione JSON-LD

Search Engine Roundtable · ★★★★☆ · 18 h fa // ID: 7836

Googlebot ha modificato il suo processo di estrazione JSON-LD, applicando ora un singolo passaggio di unescaping HTML. Questo significa che le entità HTML con doppio escaping (es. &amp;amp;) non verranno più interpretate correttamente. Gli sviluppatori devono assicurarsi che il JSON-LD sia conforme agli standard RFC 8259, utilizzando escaping JSON standard o esadecimali Unicode.
