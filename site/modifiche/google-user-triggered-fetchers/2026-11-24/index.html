## Google App Engine
**User-Agent in HTTP requests** |
AppEngine-Google; (+http://code.google.com/appengine; appid: APPID)
Appended to any custom `User-Agent` set by the app.
---|---
**Associated products** | Requests initiated by applications hosted on Google App Engine Standard Environment using the URL Fetch service, where `APPID` identifies the App Engine project. To report abusive requests from an App Engine app, use the Report suspected abuse on Google Cloud form and include the `appid` value (`https://APPID.appspot.com`, omitting any `s~` prefix), source IP address, and timestamp.
## Google Apps Script
**User-Agent in HTTP requests** |
Mozilla/5.0 (compatible; Google-Apps-Script; beanserver; +https://script.google.com; id: SCRIPT_ID)
---|---
**Associated products** | Google Apps Script fetches external URLs and APIs on behalf of user-created scripts calling the `UrlFetchApp` service across Google Workspace. To report abusive requests, use the Report suspected abuse on Google Cloud form and include the full `User-Agent` string (with `id: SCRIPT_ID`), source IP address, and timestamp.
## Google Cloud Tasks
**User-Agent in HTTP requests** |
Google-Cloud-Tasks
---|---
**Associated products** | Google Cloud Tasks dispatches asynchronous HTTP requests and scheduled webhooks to target endpoints configured by developers in Cloud Tasks HTTP target queues.
