## November 2026
November 23
### Documented additional existing crawlers and user-triggered fetchers
**What** : Updated the crawler and fetcher documentation:
* Added the following user agents to the special-case crawlers documentation: `Google-analytics-postbacks`, `Google-Calendar-Importer`, `GoogleDocs`, `Google-Edu`, `pageburst`, and `PlayStore-Google`.
* Added the following user agents to the user-triggered fetchers documentation: `AppEngine-Google`, `Google-Apps-Script`, `Google-Cloud-Tasks`, `GoogleImageProxy`, `Google Web Preview`, and `Chrome-Lighthouse`.
* Moved `APIs-Google` from special-case crawlers to the user-triggered fetchers documentation, and corrected a typo in its documented user agent string (added the missing semicolon after `APIs-Google`). If you hardcoded the old value in your code, update the string to avoid potential bugs.
**Why** : These crawlers and fetchers are not new; we're documenting existing high-volume clients that are more likely to show up in server logs and that we've received questions about. Moving `APIs-Google` reflects that its webhook push requests come from the user-triggered fetcher IP ranges and ignore `robots.txt` rules.
